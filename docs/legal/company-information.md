## Product and services / 产品及服务

The website provides a digital AI model API gateway service. Registered customers can create API keys, access enabled third-party AI models through compatible API endpoints, top up an account balance, and review API usage and billing records in the customer console.

本网站提供数字化 AI 模型 API 网关服务。注册客户可创建 API Key，通过兼容接口调用平台已启用的第三方 AI 模型、充值账户余额，并在客户控制台查看 API 用量及计费记录。

The company does not sell or ship physical goods through this website. The available models, endpoint types, and public usage prices are displayed on the [Models & Pricing](/models) page. Final payment amounts, currency, and any applicable fees are displayed before the customer confirms payment.

本网站不销售或寄送实体商品。可用模型、接口类型及公开用量价格以[模型与价格](/models)页面展示为准。客户确认支付前，结算页面会展示最终支付金额、币种及适用费用。
