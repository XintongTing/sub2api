# Digital Delivery and Logistics Policy / 数字交付与物流政策

**Effective date / 生效日期：14 August 2026 / 2026年8月14日**

## 1. Digital-only service / 纯数字化服务

This website sells access to digital AI API gateway services and account balance used to consume those services. No physical goods are sold or shipped. Accordingly, there are no shipping charges, couriers, tracking numbers, or physical delivery destinations.

本网站销售数字化 AI API 网关服务的访问权益及用于消耗该服务的账户余额，不销售或寄送实体商品，因此不存在运费、承运商、物流单号或实体收货地址。

## 2. Delivery method / 交付方式

After a payment provider confirms successful payment, the purchased amount is normally credited automatically to the customer's registered account. The customer can sign in to the console to view the balance, create or manage API keys, access enabled models, and review usage records.

支付服务商确认支付成功后，所购金额通常会自动记入客户注册账户。客户可登录控制台查看余额、创建或管理 API Key、调用已启用模型并查看用量记录。

## 3. Delivery time / 交付时间

Digital delivery is normally completed shortly after payment confirmation. Bank, card-network, payment-provider, fraud-review, webhook, or network delays may extend processing time. An order shown as pending has not yet been finally credited.

数字交付通常在支付确认后短时间内完成。银行、卡组织、支付服务商、反欺诈审核、支付通知或网络延迟可能延长处理时间。显示“处理中”的订单尚未完成最终入账。

## 4. Failed or delayed delivery / 交付失败或延迟

If payment has been deducted but the balance is not credited, first refresh the order or payment-result page and check the account's order history. If the issue remains, email [service@tokenapifuel.com](mailto:service@tokenapifuel.com) from the registered address and provide the order number, payment time, amount, currency, and a redacted payment receipt. Do not send a full card number, password, or API key.

如款项已扣除但余额未入账，请先刷新订单或支付结果页面，并查看账户订单记录。如问题仍未解决，请使用注册邮箱联系 [service@tokenapifuel.com](mailto:service@tokenapifuel.com)，提供订单号、支付时间、金额、币种及已遮盖敏感信息的支付凭证。请勿发送完整银行卡号、密码或 API Key。

## 5. Incorrect account / 充值账户错误

Delivery is made to the account that initiated the order. Customers must verify that they are signed in to the correct account before payment. Account-balance transfers are not supported unless required by applicable law or approved after a security review.

服务权益将交付至发起订单的账户。客户付款前须确认已登录正确账户。除适用法律要求或经安全审核批准外，账户余额不支持转移。
